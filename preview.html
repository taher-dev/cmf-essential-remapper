PRIVACY POLICY

Open Source Commitment & Transparency
1. Zero Internet Access (100% Offline)
CMF Essential Remapper does not request or possess the 'android.permission.INTERNET' permission. It cannot transmit data off your device under any circumstances.
2. No Data Collection or Telemetry
Zero personal data, analytics, device identifiers, or crash reporting SDKs are included. No telemetry ever runs.
3. Scoped Accessibility Service
Operates strictly with 'canRetrieveWindowContent="false"'. It cannot read screen text, passwords, or personal messages. Only physical Essential Key hardware events are filtered.
4. Local Preferences Storage
All mappings and scan codes are stored strictly on-device using Jetpack DataStore and never synced to any cloud.
5. Free & Open Source Software
Licensed under the Apache License 2.0. Complete source code is publicly auditable.
